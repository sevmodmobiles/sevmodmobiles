# Идеи и отложенные улучшения SEVMOD

Список предложений, которые обсуждались, но пока не сделаны. Новые
предложения дописываются сюда; сделанное — переносится в раздел «Сделано»
с номером коммита.

## Внешний вид

- [ ] **Заменить оставшиеся эмодзи линейными иконками** в стиле нижней панели:
  🟢/⚪ в плашке «Смена открыта / не открыта» (экран «Приход»), ⚠️ в
  «Не подтверждено сервером», 🚫 в окне «Вы не на объекте», ⏱ у опозданий
  в «Кабинете», ✕ у кнопок закрытия. *(отложено 10.10.2026)*
- [ ] **Номер версии приложения** (например, `APP_VERSION = '1.0.0'`) — показывать
  в «Профиле» или на экране входа, чтобы видеть, какая сборка открыта на телефоне
  (PWA может показывать старую из кэша).

## Расходы — добавление

- [ ] **Вариант записи периода**: сейчас период пишется строкой на каждый день
  (включая выходные). Альтернативы: одна строка с суммой за период или
  пропуск выходных.
- [ ] **«Дата погашения» при добавлении**: если в форме выбран статус
  «ОПЛАЧЕНО», ставить дату погашения автоматически.
- [ ] **Пункт «+ Добавить работника/бригадира» всегда внизу списка**, а не
  только когда совпадений не осталось (сейчас «Даврон» не предложит добавить,
  если есть «Давронбек»).
- [ ] **Состав бригады в справочнике**: сейчас состав берётся из последней
  записи с бригадиром. Альтернатива — колонка «Бригадир» напротив каждого
  работника в «Справочнике расходов».
- [ ] **Ставка** — пользователь хотел дописать требования к ставке
  («по поводу ставки и…», сообщение оборвалось). Уточнить.

## Расходы — контракты

- [ ] **Отдельный лист «Договоры»** со списком контрактов (объект, бригадир,
  сумма, авансы, дата акта), а не только платежи в листе расходов.
- [ ] **Перевод «По Графику/По Акту» → «НЕ ОПЛАЧЕНО»** сейчас только для строк
  контрактов («Работы» = «Договор»). Можно распространить на все строки с
  этими статусами.

## Расходы — просмотр и оплаты

- [ ] **Сохранять фильтры** экранов «Расходы по людям» и «Оплаты» при
  обновлении страницы (сейчас сбрасываются к «Не оплачено / По людям»).
- [ ] **Удаление целой бригады** в режиме «По бригадам».
- [ ] **Дата погашения в «Оплатах»**: не подставлять/не записывать дату для
  статусов, кроме «ОПЛАЧЕНО».
- [ ] **Восстановление удалённого из приложения** (сейчас — пунктом меню в
  таблице на листе «Журнал изменений расходов»).
- [ ] **Экран аналитики по журналу изменений**: кто, сколько и почему
  удаляет / помечает оплаченным.
